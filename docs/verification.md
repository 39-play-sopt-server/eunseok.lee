# 실제 실행 검증

2026-10-29, MySQL 9.7, 별도 로컬 포트 18081에서 실행했다. 아래는 HTTP 자동 검증 결과이며 Postman 스크린샷은 별도 첨부한다.

- 컴파일 성공
- 회원 생성 201: ID, 이름, 생성일: 통과
- 빈 회원 이름 400: 통과
- 작성자 누락 400 / 없는 작성자 404: 통과
- 게시글 생성 201: 작성자 이름, 생성일, 400자 본문 저장: 통과
- 1부터 시작하는 페이지네이션 / 생성일 최신순 / 목록 조회수 유지: 통과
- 상세 조회수 증가 / 수정 변경 감지: 통과
- 동시 상세 조회 20회: 조회수 2→22, 유실 없음: 통과
- 잘못된 페이지·크기·제목 400 / 지원하지 않는 메서드 405: 통과
- 게시글 삭제 / 삭제된 글 404: 통과
- 회원 탈퇴 시 게시글 삭제 / 없는 회원 삭제 404: 통과

기존 게시글 1개를 보존한 상태에서 검사했다. 검증용 회원과 글은 별도로 생성해 해당 데이터만 삭제했다.

Postman에서 회원 생성 201, 회원 삭제 200, 페이지네이션 목록 200을 추가로 실행하고 실제 화면을 screenshots/에 저장했다.
